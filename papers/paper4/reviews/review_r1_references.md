# Paper 4 (Federated CNN IDS) — Reference Verification, Round 1

Checked 2026-10-25 against the Crossref REST API (`api.crossref.org`), the arXiv API, and the Zenodo API. Sources: `Paper4_v1_text.md`. The reference list in `Finished_Papers/Paper4/IDS_IoT_Federated_Learning_Paper.docx` is identical to it, including the ordering faults. In-text claims were compared with each paper's title and abstract (arXiv/Crossref), plus the known content of these widely cited papers. No existing file was modified.

**Bottom line:** none of the 23 listed references is fabricated; every one exists. The problems are wrong metadata in 5 entries (one of them has the wrong first author), 5 references cited for things they do not say, a placeholder self-citation, broken numbering, one reference never cited, and a Data Availability DOI that now points to a **deleted** Zenodo record.

## 2. Structural problems

1. **Numbering and order.** The list runs 1-21, then **24, 23**, then the Data Availability heading, then **22**. In the text, [24] is first cited in §2.2 ("[5,13,24]"), before [22,23] in §2.3. Under citation-order numbering, renumber so that [24] becomes [22] and so on, and put all entries above Data Availability.
2. **Uncited reference:** [19] Flower.
3. **Citation with no reference:** "(Emmanuel, 2026)" in Data Availability is an author-year citation in a numeric paper and has no list entry.
4. **Dead Data Availability link (serious):** https://doi.org/10.5281/zenodo.21843194 resolves to a Zenodo **tombstone**: HTTP 410 "Record deleted", removed 2026-08-07, reason "personal-data". The manuscript currently promises code that is not available. Re-deposit and update the DOI, or change the statement.
5. **Duplicates:** none. Every reference except [19] is cited at least once. [1]-[18], [20]-[24] all appear in the text.
6. **Self-citation [7] is a placeholder.** The centralised baselines (0.8803 / 0.5182) depend entirely on it.
7. **Dataset citations:** TON-IoT is cited as Alsaedi et al. 2020 (correct paper; add Moustafa 2021 SCS for the network subset). UNSW-NB15 is cited as Moustafa & Slay 2015 MilCIS (correct). There is no Bot-IoT confusion.
8. Non-reference issue spotted in passing: the Conclusion's last paragraph contains a pasted fragment, "5 (-0.1306 pp vs. FedAvg), with a meaningful gain...". In addition, "0.1306 pp" in §7 should read "13.06 pp", and "+0.0174 pp" in §8 should read "+1.74 pp".
